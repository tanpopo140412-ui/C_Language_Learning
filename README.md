# C_calendar

C言語で日付計算を行うコンソールプログラム。構造体などを用いて日付を管理し、不正な日付の検証、前日・翌日の算出、曜日計算などを実装している。
C言語におけるデータ設計と関数分割、エラー処理の考え方を意識して作成した。

Try1.cファイル : カレンダーづくりのための試作その１。元は数か月前に制作したもの。
年月日を入力すると前日・次の日の年月日が表示されるようになっている。自分なりに考え書いたコードの中で条件などを考え、間違った個所を見つけるのも訂正するのに力を注いだ。
日付を更新するように書き換えることができるため、あえてポインタを使用している。
Git Hubに初めてリポジトリとして公開する練習も兼ねている。

Try2.cファイル : カレンダーづくりのための試作その２。
Try1.cファイルの論理破綻や冗長さを関数を複数に分けることや、セルフデバッグ・外部からのフィードバックなどにより時間をかけて段階的に改善したもの。
西暦１年未満の場合などはエラー表示を出し、また世界標準に合わせているため暦が変わる１５８２年以降・以前は区別しない。今はあくまで日常的なものを作成することにしている。

Try3.cファイル : カレンダー試作のためのツェラーの公式を使用した曜日を表示するためのコード。以前のコード修正を生かし、正しく動作し、かつ簡潔に書くことを重視した。公式の性質上、処理系によって変化する可能性がある。

Calender1.cファイル : 構造体を使用したカレンダーの試作。Try2.cファイルの改良版。日付を更新するのではなく、表示するものであるため、ポインタ部分を修正した。
